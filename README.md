One line of awkward small talk from one robot to another in an elevator: the machine logic shows through the politeness — "My sensors say" — the shared avoidance of eye contact is the thing neither robot wants to name, and the turn lands because neither of them has eyes.

> My sensors say you are also avoiding eye contact in this elevator. Neither of us has eyes. This is going well.

## Run it

```sh
python3 main.py
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), exactly the line and nothing else.
